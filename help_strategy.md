#### **10.1 When you get stuck - what next?**



**When do you prefer using AI vs. searching Google?**

&#x09;

&#x09;I typically use AI as pretty much every information that I need it can provide. However, for a more specific problem that have a very small niche, sometimes I go to google and visit some websites like stock over flow to read some forums out there because some users the same problems have solutions that can help. 



**How do you decide when to ask a colleague instead?**



&#x09;I ask colleagues if it involves sensitive information and depending on the urgency of the problem. 



**What challenges do developers face when troubleshooting alone?**

&#x09;

&#x09;When troubleshooting, there might be variables that you can't expect to happen and there will always be problems that you could experience for the first time. So having a system to troubleshoot it really helps to come up in a solution that is best for the given time.
