**What is the purpose of CI/CD?**



&#x09;Continuous integration(CI) is a practice which development teams employ or use to continuously merge and integrate changes into the main codebase safely and efficiently while Continuous delivery(CD) is a practice which development teams use to ensure that there were continuous deployment within the team. This 2 ensures that every changes is safe, tested and maintainable for future actions.



**How does automating style checks improve project quality?**



&#x09;Automating style checks improve project quality by ensuring that things are consistent all throughout the whole codebase. It makes things predictable and easier to debug and understand.



**What are some challenges with enforcing checks in CI/CD?**



&#x09;It slows down pipelines which can cause for longer wait times just to get feedback, Sometimes it flags things that aren't really a problem, too strict and flaky when testing.



**How do CI/Cd pipelines differ between small projects and large teams?** 



&#x09;Smaller projects tend to have faster pipelines while larger teams have slower pipelines due to the project being big and more checks is done taking time in return.
