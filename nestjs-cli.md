#### **6.5 Using NestJS CLI for Scaffolding**



**How does the NestJS CLI help streamline development?**



&#x09;The NestJS CLI reduces repetitive setup work. Instead of manually creating the dependencies you need, you generate them automatically. Nest creates the files and wires them together. This in turn makes the development faster, creates fewer mistakes, registration becomes automatic and onboarding becomes easier.



**What is the purpose of nest generate?**



&#x09;nest generate or nest g creates NestJS building blocks.



**How does using the CLI ensure consistency across the codebase?**



&#x09;Large applications become difficult when ever developer structures code differently. The CLI solves that by generating the same patterns every time. It makes things consistent althroughout, standard and predictable which in turn makes things easier to maintain overall.



**What types of files and templates does the CLI create by default?**



&#x09;The CLI generates different templates; It generates a template for the new project, module, controller, services and resources.
